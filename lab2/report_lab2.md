## 3. Теоретичні розрахунки та лістинг

### 3.1. Апроксимація періодичного сигналу рядом Фур'є

Кількість відліків $N = 6$. Максимальна кількість гармонік (частота Найквіста) $K = 3$.
Постійна складова: $a_0 = 4.3333$ ($a_0/2 = 2.1667$).

**Розраховані коефіцієнти (уточнений розрахунок):**

* **Гармоніка 1 ($m=1$):** $a_1 = 1.1667$, $b_1 = -0.2887$

* **Гармоніка 2 ($m=2$):** $a_2 = 0.8333$, $b_2 = -0.2887$

* **Гармоніка 3 ($m=3$):** $a_3 = -0.1667$, $b_3 = 0.0000$


**Математична особливість:** Для останньої гармоніки Найквіста ($m = N/2 = 3$) значення $\cos(3 \cdot \frac{2\pi}{6}n) = \cos(\pi n) = (-1)^n$. Сума квадратів косинусів для неї становить $N = 6$, а не $N/2 = 3$, як для інших частот. Тому математично точний множник для $a_3$ становить $\frac{1}{N}$. Використання загального множника $\frac{2}{N}$ з методичних вказівок дає вдвічі більший коефіцієнт $a_3 = -0.3333$ і спричиняє похибку інтерполяції.

### 3.2. Експоненціальна апроксимація (МНК)

Для застосування МНК функція лінеаризується шляхом логарифмування: $\ln(y) = A + Bx$.
Система нормальних рівнянь:


$$\begin{cases} A \cdot N + B \sum x_n = \sum \ln(y_n) \\ A \sum x_n + B \sum x_n^2 = \sum x_n \ln(y_n) \end{cases}$$

Для варіанту 5:


$$\begin{cases} 6A + 10.5B = 3.8712 \\ 10.5A + 22.75B = 8.2917 \end{cases}$$

**Отримані коефіцієнти:**

* $A = 0.0384$

* $B = 0.3468$

* **Рівняння функції:** $f(x) = e^{0.0384} \cdot e^{0.3468x} = 1.0391 \cdot e^{0.3468x}$

## 5. Відповіді на контрольні запитання (стисло)

1. **Що позначає 0-ва гармоніка у ряді Фур'є?**
Це постійна складова сигналу ($a_0/2$), яка визначає його середнє значення. Вона показує, наскільки загальний рівень сигналу зміщений відносно нульової осі.
2. **Чому для останньої гармоніки (частоти Найквіста) коефіцієнт $b_m$ дорівнює нулю?**
Коефіцієнти $b_m$ розраховуються через синус. Для частоти $m = N/2$ аргумент синуса завжди кратний $\pi$ (тобто $\sin(\pi n)$), що для будь-якого цілого $n$ тотожно дорівнює нулю.
3. **Навіщо проводити лінеаризацію при експоненціальній апроксимації?**
Метод найменших квадратів (МНК) у матричному вигляді застосовується до лінійних залежностей. Логарифмування експоненціальної функції перетворює її на лінійне рівняння прямої $\ln(y) = A + Bx$, що дозволяє легко знайти коефіцієнти через розв'язання СЛАР.
4. **У чому різниця між результатами двох графіків у завданні?**
Уточнений ряд Фур'є здійснює точну *інтерполяцію* (крива проходить рівно через усі опорні точки і є періодичною). Експоненціальна функція виконує *апроксимацію* — згладжує дані, не проходячи через кожну точку, але відображаючи загальний монотонний тренд росту.

## 6. Висновок

Під час виконання лабораторної роботи реалізовано методи спектрального аналізу дискретних сигналів (ряд Фур'є) та згладжування нелінійних даних (експоненціальна апроксимація).

Дослідження виявило, що буквальне застосування узагальненої формули для частоти Найквіста ($m = N/2$) призводить до подвоєння останньої гармоніки через властивість суми квадратів косинусів, яка на цій частоті дорівнює $N$, а не $N/2$. Застосування уточненого множника $1/N$ дозволило досягти ідеальної інтерполяції вузлових точок. Експоненціальна апроксимація за допомогою МНК з попереднім логарифмуванням успішно згладила вхідний масив, отримавши функцію $f(x) = 1.0391 \cdot e^{0.3468x}$, що адекватно описує експоненціальний тренд зростання даних.
